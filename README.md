# ⏱ Time Timer

깔끔하고 기능이 풍부한 타임 타이머 웹앱입니다.  
## ✨ 기능

### 🎯 타이머
- 시/분/초 직접 입력
- 빠른 설정 버튼 (1분, 5분, 10분, 15분, 25분, 30분, 45분, 1시간)
- 클릭 또는 버튼으로 시작/정지
- 1분 추가 기능

### 🎨 디자인
- **7가지 프리셋**: Default, Minimal, Ocean, Forest, Sunset, Aurora, Chalk
- **커스텀 색상**: 배경/패널/강조색/트랙/텍스트 색상 자유 설정
- **이미지 배경**: 이미지 업로드로 타이머 배경 변경 (드래그 앤 드롭 지원)

### ⚙️ 설정
- 알림 소리 on/off + 볼륨 조절
- 알림음 5가지 프리셋 + 커스텀 업로드
- 커스텀 음원 업로드 (MP3, WAV 등 모든 오디오 파일)
- 디지털 시계 표시 on/off
- 선형 진행 바 표시
- 경과 시간 모드 (남은 시간 ↔ 경과 시간)
- 자동 반복
- 눈금 표시
- 그림자(글로우) 효과

### 📱 기타
- 전체화면 모드
- 완전한 반응형 (PC + 모바일)
- 모바일에서 섹션 접기/펼치기
- 유튜브 음악 재생

## ⌨️ 키보드 단축키 (PC)

| 키 | 기능 |
|---|---|
| `Space` | 시작 / 일시정지 |
| `R` | 리셋 |
| `L` | 1분 추가 |
| `F` | 전체화면 전환 |
| `M` | 음소거 토글 |
